# TVPlayout 13.0

Proyecto base para el panel/platoout OBS.

La carpeta queda reservada para el código fuente de TVPlayout 13.0 y sus módulos asociados (TMDB, OBS WebSocket, Scheduler, Playout, HLS/TS, Recovery y titulador nativo).

No se deben guardar aquí credenciales, `tvplayout.db`, `.venv`, FFmpeg ni cachés generadas.

TVPlayout 12.9 - Título automático + preparación IMDb

Esta versión parte de TVPlayout 12.9 TS TUNED.

Para probar el título en OBS:
1. Crea una fuente de texto en la misma escena del playout.
2. Reinicia TVPlayout.
3. En SALIDA OBS selecciona la nueva escena/fuente en "Título automático en pantalla".
4. Activa "Activar título".
5. Reproduce/toma una película.

No requiere instalar una librería adicional para esta función.
